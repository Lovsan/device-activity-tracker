# Staff Hiring Banners

This directory contains three different hiring banner designs for the Device Activity Tracker project.

## Banner Designs

### 1. hiring-banner-1.svg - React/Node.js Theme (Blue & Cyan)
- **Color Scheme**: Blue gradient (#0ea5e9 to #3b82f6)
- **Target Audience**: React & Node.js Developers
- **Tech Stack Featured**: React ⚛, Node.js 🟢, TypeScript, Code 💻
- **Call to Action**: "APPLY NOW"
- **Style**: Modern, tech-focused with decorative circles

### 2. hiring-banner-2.svg - Python Theme (Green & Yellow)
- **Color Scheme**: Green gradient (#10b981 to #059669)
- **Target Audience**: Python Developers
- **Focus Areas**: Machine Learning, Data Analysis, Backend Development
- **Features**: Python logo representation (blue & yellow circles)
- **Call to Action**: "JOIN US TODAY"
- **Style**: Professional with geometric decorative elements

### 3. hiring-banner-3.svg - Multi-tech Theme (Purple & Pink)
- **Color Scheme**: Purple to Pink gradient (#8b5cf6 to #ec4899)
- **Target Audience**: Full Stack, Security, Research positions
- **Tech Stack Featured**: React, Python, Node.js, Go, Rust
- **Benefits Highlighted**: 💰 Competitive Pay, 🏠 Remote Work, 🚀 Great Culture
- **Call to Action**: "VIEW OPEN POSITIONS →"
- **Style**: Modern with grid pattern background

## Usage

These banners can be used:
- On the company website's careers page
- In social media recruitment posts
- In email campaigns for hiring
- At tech conferences and meetups
- On job posting sites

## Dimensions

All banners are:
- **Width**: 1200px
- **Height**: 400px
- **Format**: SVG (scalable without quality loss)

## Customization

The SVG format allows for easy customization:
- Colors can be changed in the gradient definitions
- Text can be modified directly
- Icons and decorative elements can be adjusted
- Export to PNG or other formats as needed
